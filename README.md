# To-Do List App

A simple and clean To-Do List web app built with HTML, CSS, and JavaScript. Add your tasks, and mark them as completed once you're done.

## Features

- Add new tasks
- Mark tasks as completed (completed tasks are visually marked)
- Delete tasks you no longer need
- Simple, responsive layout

## Built With

| Technology | Purpose |
|------------|---------|
| HTML5 | Structure of the page |
| CSS3 | Styling and layout |
| JavaScript | Logic (add, complete, delete tasks) |

## Project Structure

```
todo-list/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Use

1. Type your task in the input box.
2. Click the **Add** button (or press **Enter**) to add it to the list.
3. Click on a task (or its checkbox) when you finish it to mark it as completed.
4. Click the **Delete** button to remove a task.
